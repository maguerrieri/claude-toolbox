## The Starforged SRD (CC BY 4.0)

**Ironsworn: Starforged** SRD content (moves, assets, oracles, setting truths, and the stats, meters, impacts and legacy tracks), © 2022 Shawn Tomkin, licensed under the **Creative Commons Attribution 4.0 International (CC BY 4.0)** license: https://creativecommons.org/licenses/by/4.0/

It comes from the machine-readable edition published by **Datasworn** (https://github.com/rsek/datasworn), at a pinned ref:

- repo `rsek/datasworn`, tag `v0.1.0-prerelease`, commit `e643a75263c1cb3e845a0c0789879ff4e8b49532`
- file `datasworn/starforged/starforged.json`, sha256 `6246ed6da109cf1586f80ae3b8238feffca2ebaa00a37e3437e1b9f7b7e313c9`

`plugins/gm/tools/datasworn-import` converts it into this adapter's formats; every file it writes starts with a "Generated by tools/datasworn-import" comment. Those files are:

- `oracles/**/*.md` (every rollable table)
- `rules/moves.md`, `rules/assets.md`, `rules/assets/*.md`, `rules/truths.md`, `rules/oracles.md`
- `sheet-template.md`

Changes made: the JSON is converted to Markdown tables and rules files; Datasworn's cross-references are rewritten as this adapter's file paths; nothing is added to or omitted from the moves, assets, tables or truths. To regenerate, or to check the tree against the pin, run `plugins/gm/tools/datasworn-import` (or `--check`); `--help` says how to move the pin.
